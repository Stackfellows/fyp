# FYP Student Complaint & Grievance Portal - Frontend

A modern, responsive, and intuitive React.js frontend for the **University Final Year Project (FYP)** Student Complaint and Grievance Management System.

---

## 🚀 Features

- **Student Portal**: Lodge academic, FYP supervisor, and hardware lab grievances with file attachments.
- **Real-Time Ticket Tracking**: Check ticket statuses (`Pending`, `In Progress`, `Resolved`, `Rejected`).
- **Interactive Discussion Thread**: Two-way communication between students and academic administration.
- **Faculty / Admin Console**: Centralized moderation, department filtering, status updates, and announcement broadcast.
- **Seamless PHP Backend Integration**: Connected to lightweight PHP REST APIs.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + Vite
- **Styling**: Tailwind CSS + Custom Design System
- **State Management**: Redux Toolkit
- **Icons**: Lucide React
- **Notifications**: React Hot Toast
- **Data Visualization**: Recharts

---

## 💻 Running the Frontend

```bash
# 1. Install dependencies (if not already installed)
npm install

# 2. Run the Vite development server
npm run dev
```

Visit: `http://localhost:5173`
